# 苏程记录 V1 最终真机验收清单

只需在手机上按顺序操作；每项看到右侧结果即为通过。

- [ ] 打开小程序：能进入首页，无白屏或持续加载。
- [ ] 五个 Tab：首页、学校库、成绩、目标、我的都能打开。
- [ ] 首页：能看到当前档案、中考倒计时、最近成绩和目标学校区域。
- [ ] 学校库：显示“找到 55 所学校”。
- [ ] 搜索：输入“苏州中学”后能看到对应学校。
- [ ] 区域筛选：选择一个区域后列表随之变化。
- [ ] 更多筛选：学校类型、年份和分数范围可正常使用，重置后恢复。
- [ ] 学校详情：能看到学校名称、历史分数线、年份和公开来源。
- [ ] 学校图片：有图时正常显示；无图或加载失败时页面文字和分数仍正常。
- [ ] 目标学校：在详情页加入目标后，目标 Tab 能看到；移出后消失。
- [ ] 记录成绩：新增一条考试名称、日期和 0–740 之间总分后能保存。
- [ ] 成绩趋势：新增成绩后趋势和最近记录正常更新。
- [ ] 输入保护：尝试输入 741 分时不能保存，并有中文提示。
- [ ] 学生档案：能创建、切换和改名；不同档案的数据互不混淆。
- [ ] 数据备份：能导出备份并出现微信发送选择界面。
- [ ] 恢复备份：选择有效备份后能预览并按所选方式恢复。
- [ ] 帮助：常见问题内容可读，客服邮箱和微信号可复制。
- [ ] 隐私说明：能看到数据保存在本机、不登录、不读取手机号和定位等说明。
- [ ] 断网查看：关闭手机网络后重新进入学校库，学校和分数仍可查看。
- [ ] 重新联网：恢复网络并在首页或学校库下拉刷新，页面继续正常使用。
- [ ] 返回与重启：关闭后重新打开，小程序仍能正常进入，原有成绩、目标和档案未丢失。
