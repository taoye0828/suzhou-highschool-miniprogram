## 成绩趋势真实根因与修复

旧实现存在三个共同问题：

1. `summarizeScoreRecords` 直接依赖调用方传入顺序，仅做 `slice(-10)`，没有在趋势层统一执行“日期、createdAt、id”稳定排序。
2. 图表纵轴按当前数据动态最小值/最大值计算，且 Canvas 固定使用 640 逻辑宽度，页面实际宽度与绘图坐标可能不一致。
3. “最近变化”错误使用可见记录第一条和最后一条计算，而不是最后一条减倒数第二条。

`utils/score-trend.js` 现在提供：

- `sortScoreRecords`
- `getVisibleTrendRecords`
- `calculateScoreStatistics`
- `calculateChartPoints`
- `prepareScoreTrendData`

完整排序后取最新 10 条，列表、统计和折线共用同一批 ID。横坐标按显示索引生成，纵轴固定为 0–740 并保留内边距；Canvas 首次绘制时测量真实宽度，新增、删除、清空和返回页面均重绘。

专项结果：

- 0/1/2/3/10/11 条全部通过。
- `740、740、650` 保留 3 个独立点和 3 个横轴位置；前两个点水平，第二个到第三个向下。
- 同分、同日、乱序、最近两次变化、平均/最高/最低、坐标边界和图表/列表 ID 一致性全部通过。

## 自动目标学校推荐

入口位于成绩分析 Tab，首页提供“输入成绩，看目标学校”快捷入口。

- 分差：`difference = userScore - referenceScore`
- 冲刺：`-30 <= difference < 0`
- 目标：`0 <= difference <= 15`
- 保底：`difference > 15`
- 参考分：不晚于目标年份的最新已收录年份；同校同年多条取最高参考分。
- 排序：冲刺差距最小优先；目标绝对差距最小优先；保底领先分数由小到大。
- 每组最多 5 所，不补造无分数线学校，不重复，不跨分类。

卡片显示学校、地区、类型、参考分、参考年份、当前成绩、分差、等级、详情和加入目标操作。加入目标只在用户点击后保存 `schoolId / schoolName / level / referenceScore / referenceYear`；同校再次添加更新原记录。保存成绩为独立按钮，同日同名同分不会重复创建。
