# 苏程记录 1.2.0 版本更新说明

1.2.0 起，学校与历史分数线等公开数据由后台统一发布：后台保存修改后通过发布中心生成不可变数据 Release，小程序启动或回到前台时通过 `https://api.royalcup.top` 获取最新版本，逐文件校验 SHA-256 和内容结构后整体切换。

网络不可用或数据校验失败时自动使用上一次校验通过的本机缓存；首次安装没有缓存时使用代码包内的 55 所学校和 146 条已核实历史分数线（2025 年 103 条、2026 年 43 条，总分上限为 740）。远程更新不会写入或上传任何用户数据。

本次上线前 P0 修复完成了备份页两个正式入口：查看备份范围会根据当前真实 Backup v3 Schema 展示各类本机用户数据及数量，并说明不会备份的内容；发送备份会在每次点击时生成并校验最新 JSON 文件，再调用微信官方文件发送界面。用户取消、文件生成失败或微信接口失败均不会显示成功。

用户成绩、目标学校和学生档案只保存在本机。

> 可直接复制到微信开发者工具。上传审核前仍须按最终清单确认真机微信文件发送面板实际打开并能选择联系人；开发者工具中的 API 调用验证不能替代这一步。
