# 苏程记录 V1 微信审核说明

## 小程序与版本用途

- 小程序名称：苏程记录
- 本版本用于首版正式上线候选验收。
- 主要功能：查询苏州高中基础信息与已核实历史录取分数线；在本机记录考试总分、目标学校和学生档案；在本机导出、恢复或清理备份。

## 审核体验路径

1. 首页：查看当前档案、中考倒计时、最近成绩和目标学校入口。
2. 学校库：搜索学校，并按区域、学校类型、年份和历史参考分筛选。
3. 学校详情：查看学校基础信息、历史录取分数线、公开来源，并手动加入目标学校。
4. 成绩：新增考试名称、日期与总分，查看最近成绩趋势。
5. 目标：查看用户手动加入的目标学校与历史参考分差值。
6. 我的：管理学生档案、备份恢复、帮助与隐私说明。

## 数据与产品边界

- 正式数据包含 55 所学校和 146 条已核实历史分数线，其中 2025 年 103 条、2026 年 43 条，总分上限为 740。
- 学校及历史分数线来自学校官网、教育部门官网、教育考试机构官网或公开发布资料；学校详情展示来源名称、链接和核对日期。
- 历史分数线只用于了解过去公开信息，不代表未来录取结果。
- 本产品不是志愿推荐或录取预测工具，不计算录取概率，不给出“能否录取”“稳妥/冲刺”等结论。
- 不需要登录；不收集 OpenID、UnionID、手机号或位置；无支付、广告、AI、社区和用户行为统计。
- 正式上线前将通过 `https://api.royalcup.top` 只读获取学校公开数据；网络失败时使用已验证缓存或包内正式数据。当前候选包已保留完整包内数据，生产服务与微信合法域名尚未完成时不会影响离线内容展示。
- 用户成绩、目标学校、学生档案及备份均只保存在用户设备，不上传到服务器。
- 剪贴板仅在用户主动复制客服方式、学校信息或来源链接时写入；MessageFile 仅在用户主动选择备份文件恢复时读取。

## 微信平台配置

- 提交审核前配置门禁：先完成 `https://api.royalcup.top` 的生产发布、可信 HTTPS 和公开接口验收，再将该域名加入 request 合法域名。
- 当前代码仅通过 `wx.request` 读取 JSON；学校图片使用同一 HTTPS 域名的普通图片地址，当前代码未调用 `wx.downloadFile`。只有后续真实代码使用 `wx.downloadFile` 时才需要配置 downloadFile 合法域名。
- 当前状态：上述生产服务和 request 合法域名尚未完成，开发者工具会回退到本机正式数据；未完成该门禁前不得上传审核版本，也不得将本说明当作已完成配置的证明。

审核员可重点体验学校搜索/筛选、学校详情与历史分数、记录成绩、目标学校、档案、备份恢复、帮助和隐私页。
