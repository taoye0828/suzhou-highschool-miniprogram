# V1 考试模板规格

- 正式入口：“我的 → 考试模板与分值方案”，成绩记录表单也可直接选择模板。
- 内置模板唯一来源为 `shared-spec/product_rules_v1.json`，不写入用户档案，不可修改或删除，可复制为自定义模板。
- 自定义模板保存在当前 `profileData.examTemplates`，支持新建、查看、编辑、复制、删除、引用数、版本冲突、幂等和多档案隔离。
- 模板只预填考试名称、类型、分值方案及学科/排名/复盘显示选项；选择模板不会自动创建考试。
- 删除模板不删除历史考试，历史记录可保留 `examTemplateId` 作为来源快照标识。

验证：`V1-EXAM-001`、`V1-EXAM-002`、`V1-EXAM-006`、`V1-EXAM-007`。
