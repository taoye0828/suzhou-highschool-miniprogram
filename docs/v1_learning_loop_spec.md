# V1 学习闭环规格

- 错题只保存文本字段，不保存图片；重复出错必须由用户主动确认。
- 错题与学习任务在正式存储服务的一次事务中建立双向关联；删除来源不删除独立任务，删除任务会移除错题侧关联 ID。
- 周计划固定周一开始、周日结束；未完成任务不自动移动，只有用户主动复制才进入下周；删除计划不删除任务。
- 阶段目标支持总分、学科分、得分率和任务完成率。没有可比较数据时显示“暂无可比较记录”，不会用 0 代替。
- 阶段复盘保存目标、起止数据、任务摘要和考试摘要的不可变快照；总结文字由用户填写，不使用 AI。
- 全部实体按当前档案隔离，并接入 Schema v5、Backup v3、Restore Point v2、清除、迁移和版本冲突链路。
