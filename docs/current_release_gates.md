# 苏程记录 2.0 当前正式候选门禁

当前正式产品冻结基线是：10 个页面、5 个 Tab、55 所学校、146 条历史分数线、740 分上限，以及用户数据完全保存在本机。

统一入口：

```bash
node scripts/verify_production_release_candidate.js
```

该入口包含 36 个与当前正式产品一致的脚本门禁，覆盖 FCP 页面冻结、真实性扫描、数据完整性、Storage 迁移、备份文件真实写入与恢复、故障注入、事务、上传包排除，以及远程服务代码的三层回退能力。

`verify_real_user_functionality_v2.js` 保留原 13 项真实性检查，新增 1 项十页关键按钮副作用扫描和 14 项备份真实性回归。备份回归不再以“handler 存在”作为通过条件，而是实际验证范围 Schema/数量、最新文件写入与存在性、合法 JSON、`wx.shareFileMessage` 参数、取消/失败分支、生成失败禁止分享，以及隔离数据导出→清除→恢复→重启→清理闭环。

## 备份 P0 硬门禁

- “查看备份范围”必须由当前真实 Backup v3 JSON 生成，所有当前用户字段均被归类，0 数量不隐藏，并明确不包含学校公开数据库、后台或远程数据、微信聊天记录和系统文件。
- “发送备份”每次点击都重新生成并校验最新文件；文件名为 `suzhou_highschool_backup_YYYYMMDDHHMMSS.json`，真实存在且能重新读取通过校验后，才允许调用微信官方 `wx.shareFileMessage`。
- 用户取消、分享接口失败、文件生成或校验失败均不得显示成功；技术错误只写开发日志，普通用户只看到自然中文。
- `wx.showModal` 的确认/取消按钮文案必须遵守微信最多 4 个字符的限制；十页扫描会拒绝超长的静态按钮文案，避免确认框调用失败后形成“无反应”按钮。
- 脚本与开发者工具通过不能代替真机联系人选择面板；真机“范围正确”和“发送面板打开并可选择联系人”是上传审核前硬门禁。

仓库保留的其他 RC/V1 专项脚本属于历史功能阶段，其中部分会读取已按 FCP 要求删除的对比、收藏、复盘、任务、报告等页面。它们用于历史追溯，不得作为恢复已删除功能的依据。

## 2.0 正式运行边界

- 2.0 直接使用代码包中的 55 所学校和 146 条历史分数线，不依赖生产服务器或网络。
- `remotePublicDataEnabled` 在正式配置中固定为 `false`；启动、回前台、首页和学校库均不会请求远程公开数据接口。
- `urlCheck` 保持开启，未通过关闭合法域名校验来隐藏问题。
- 远程公开数据服务代码继续由 29 场景验证其 manifest、SHA、原子缓存、last-known-good 和包内 fallback 行为，但不宣传为 2.0 用户功能。
- 当前正式学校图片为 0、正式公告为 0；学校无图布局可用，公告区域隐藏；包内 6 项 FAQ 与客服联系方式可用。

## 当前现场状态（2026-08-16）

- `https://api.royalcup.top` 已通过 DNS、免费可信 HTTPS、Release V2、SHA、数量、缓存头和只读访问控制验收，作为未来远程公开数据能力保留。
- 苏程记录 2.0 正式候选仍使用包内数据，不发起 `wx.request`；API 上线不会改变本版本运行链路，也不新增 request 合法域名依赖。
- 自动门禁、微信开发者工具和 Git 状态以本次终审最终报告中的实测结果为准。
- 未购买或开通服务器、数据库、对象存储、CDN、证书、API、插件或 SaaS。
