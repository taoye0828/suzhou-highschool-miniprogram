# RC7-1 双端功能升级报告

日期：2026-07-26

## 1. 本轮目标

在不进入发布流程、不修改正式学校与分数线数据的前提下，完成全局学校智能匹配、目标高中管理增强、成绩分析目标关联，并同步到独立 Flutter 仓库。

## 2. 搜索系统设计

- 小程序统一入口：`utils/school-search.js`。
- 预处理：移除全部空白字符并统一大小写。
- 匹配顺序：
  1. 学校完整名称包含关键词；
  2. 学校别名包含关键词；
  3. 关键词字符按顺序出现在名称或别名中；
  4. 关键词字符分散存在于名称、别名或学校区域上下文中。
- 同等级结果保持稳定排序，并优先展示名称较短的结果。
- 正式数据名称不因示例文案而改写；`南航` 返回正式记录“南京航空航天大学苏州附属中学”。

## 3. 支持页面

- 首页快速搜索并跳转学校详情。
- 学校库搜索与组合筛选。
- 收藏列表内搜索。
- 目标学校搜索与详情选择。
- 高中对比选择前搜索。
- 成绩分析结果按学校关键词筛选。
- 所有搜索结果均复用学校详情跳转。

## 4. 目标高中管理

- 学校详情选择冲刺、目标或保底后加入目标。
- 目标列表支持添加、列表内修改等级、删除、查看详情和确认后清空全部。
- 默认按冲刺、目标、保底排序。
- 显示学校名称、等级、最新历史参考分、参考年份、我的成绩和当前差距。
- 继续使用 `schoolId`、`schoolName`、`level` 本机记录结构，同校保存执行更新而不是重复新增。

## 5. 成绩分析增强

- 结果标识学校是否已加入目标及其目标等级。
- 显示当前成绩、历史参考分、分差和提升空间。
- 只使用已收录历史公开数据和固定分差区间，不包含“保证录取”“预测录取”或“一定考上”等承诺。
