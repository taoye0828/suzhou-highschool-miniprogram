# 苏程记录 1.2.0 微信审核说明

## 小程序与版本用途

- 小程序名称：苏程记录
- 产品正式版本：1.2.0
- 主要功能：查询苏州高中基础信息与已核实历史录取分数线；在本机记录考试总分、目标学校和学生档案；查看本机备份范围并导出、发送、恢复或清理备份。

## 审核体验路径

1. 首页：查看当前档案、中考倒计时、最近成绩和目标学校入口。
2. 学校库：搜索学校，并按区域、学校类型、年份和历史参考分筛选。
3. 学校详情：查看学校基础信息、历史录取分数线、公开来源，并手动加入目标学校。
4. 成绩：新增考试名称、日期与总分，查看最近成绩趋势。
5. 目标：查看用户手动加入的目标学校与历史参考分差值。
6. 我的：管理学生档案；进入“数据备份与恢复”查看备份范围和数量、生成 JSON 备份，并由用户主动打开微信文件发送界面；也可选择备份文件恢复。

## 数据与产品边界

- 1.2.0 的学校与历史分数线由后台统一发布。小程序启动和回到前台时，通过微信 `wx.request` 从 `https://api.royalcup.top`（已配置为正式 request 合法域名）获取后台发布的数据版本并校验 SHA-256 与内容结构；校验通过后整体切换为最新内容。
- 网络不可用或数据校验失败时，小程序继续使用上一次校验通过后完整保存的本机缓存（last-known-good）；首次安装没有缓存时，使用代码包内的 55 所学校和 146 条已核实历史分数线（2025 年 103 条、2026 年 43 条，总分上限为 740）。核心查询始终可用，断网仍可使用。
- 学校及历史分数线来自学校官网、教育部门官网、教育考试机构官网或公开发布资料；学校详情展示来源名称、链接和核对日期。
- 历史分数线只用于了解过去公开信息，不代表未来录取结果。
- 本产品不是志愿推荐或录取预测工具，不计算录取概率，不给出“能否录取”“稳妥/冲刺”等结论。
- 学校图片和公告由后台发布；没有图片时显示文字标识，公告为空时整区隐藏，不使用演示图片或公告。
- 不需要登录；不收集 OpenID、UnionID、手机号或位置；无支付、广告、AI、社区、云开发和用户行为统计。
- 远程获取的内容仅包含公开数据（学校、历史分数线、图片、公告、客服与展示设置）；用户成绩、目标学校、学生档案及备份均只保存在用户设备，不上传到服务器。
- “查看备份范围”直接根据当前 Backup v3 JSON Schema 展示学生档案、成绩记录、目标学校、历史兼容数据和本地设置；数量为 0 的类别也会显示。范围同时明确不包含学校公开数据库、后台或远程数据、微信聊天记录和系统文件。
- 用户每次点击“发送备份”都会先根据当时的本机数据生成并校验最新 `suzhou_highschool_backup_YYYYMMDDHHMMSS.json`，再在用户确认后调用微信官方 `wx.shareFileMessage` 打开文件发送界面；不会复用旧缓存文件，不会自动发送、上传或保存到服务器。取消或接口失败不会提示成功。
- 剪贴板仅在用户主动复制客服方式、学校信息或来源链接时写入；MessageFile 仅在用户主动选择备份文件恢复时读取；备份文件仅在用户主动确认时调用微信发送界面。
