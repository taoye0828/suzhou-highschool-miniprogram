# 苏程记录 V1 功能冻结报告

## 冻结结论

- 代码冻结级别：`V1_CODE_FREEZE_READY`。
- 上架前体验冻结：`PRE_RELEASE_UX_FREEZE_CONFIRMED = false`。
- 功能清单无 `partial`；32 项首发能力均有正式入口，排除项和开发专用项已单列。
- 本结论只覆盖小程序仓库，不表示 Flutter 仓库已同步。

## 首发范围

正式五个 Tab 为首页、学校库、成绩、目标规划、我的。首发包含学校筛选/详情/收藏/对比、考试记录/模板/分值方案/原始分与得分率趋势、复盘/失分原因/错题、学习任务/周计划/阶段目标/阶段复盘、历史分差参考、目标学校和学校个人状态、全局搜索、文本和 JSON 报告、多档案、Backup v3、Restore Point v2、数据检查与启动恢复。

历史分差规则固定为 `difference = userScore - referenceScore`：冲刺 `-30 <= difference < 0`，目标 `0 <= difference <= 15`，保底 `difference > 15`，每组最多 5 所。只有完整 740 总分体系、快照完整且数据健康合格的考试可以作为参考成绩；得分率和其他满分考试不会换算成 740。

## 排除与开发专用

PDF、本地应用锁、生物识别、图片上传、登录、后台、云同步、AI、推送和正式 2027 数据均不在 V1。2027 候选数据与维护工具只存在于 `docs/` 和 `scripts/`，没有运行时调用，并由上传包规则排除。

## 数据与版本

- Storage Schema v5，兼容读取 v4。
- Backup Format v3（SHA-256），兼容读取 v2 FNV-1a。
- Restore Point Format v2，兼容读取 v1。
- 正式数据：55 所学校；2025 年 103 条；2026 年 43 条；合计 146 条；正式 2027 年 0 条；最高分 740。
- 三份正式数据 raw SHA-256 和 semantic SHA-256 均与任务基线一致，详见最终证据。

## 冻结后允许范围

上架前只进入体验优化：布局、视觉层级、字体、间距、文案、操作步骤、空/加载/错误状态、安全区、多尺寸/iPad、性能、卡顿、崩溃、数据丢失缺陷、审核合规、真机问题、正式官方数据更新和上架材料。新的业务想法只记录到 `docs/post_launch_feature_candidates.md`。

## 平台边界

本轮未用微信开发者工具对最终 `RC11-FINAL-MP` 提交执行普通编译，也未完成 Problems、Console、六种尺寸、真实文件分享、真实恢复点、多档案、手机预览、体验版上传或审核。因此不得确认 `PRE_RELEASE_UX_FREEZE_CONFIRMED`。
